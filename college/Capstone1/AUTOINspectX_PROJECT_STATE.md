## 1. Executive Summary

AutoInspect-X is a final-year academic capstone: a **photo-first** vehicle
damage inspection system. A photograph is uploaded, a capture-quality gate
accepts or rejects it, a segmentation model produces a pixel-level damage mask,
and the system explains its findings — and its confidence — honestly.

> **Scope change (ADR 0011, accepted 2026-09-21):** repair-cost prediction,
> repair-action prediction, and the questionnaire flow that fed them are
> **removed**. The research core is now a **CNN + Transformer hybrid
> (CarddHybrid, ADR 0010)** segmentation model compared against the plain U-Net
> baseline for **segmentation quality and confidence honesty** on CarDD. This
> is the reason this document and the research report no longer describe a
> multimodal cost-estimation pipeline.

**What exists today (IMPLEMENTED)**

- A working **ML baseline**: a raw-PyTorch U-Net (`CarddUNet`) trained on the
  CarDD COCO dataset, producing an underfit 5-epoch CE checkpoint
  (`cardd_baseline_ce`) that is the demo inference model (now SUPERSEDED).
- A **hybrid model**: `CarddHybrid` (CNN encoder + transformer
  bottleneck + skip decoder, ~3.2 M params) implemented (ADR 0010) and
  **trained** (`cardd_hybrid_ce`, 2026-09-21) — measured results in §3.
- A **full product demo**: Next.js frontend (ChatGPT-style composer with photo
  attachment, inline analysis results, consent) calling a FastAPI backend
  (LangChain ChatGroq or offline stub assistant, segmentation inference engine,
  image/consent/storage services).
- **Quality gates**: ruff, mypy (strict), pytest, and a Playwright suite
  configured in GitHub Actions CI.
- **Honesty infrastructure**: the engine, API, and UI always label results as
  predicted-mask / low-confidence / image-denominator-ratio; **no cost or
  quote field exists anywhere** (enforced by tests).

**Key verified numbers (MEASURED RESULT)**

- Baseline `cardd_baseline_ce`: val mIoU **0.0475**, test mIoU **0.0500**;
  pixel accuracy ~0.76 (≈ background prior); small-damage slice IoU **≈0**.
- Hybrid `cardd_hybrid_ce` (5 epochs, seed 0, same harness as baseline):
  val mIoU **0.0504**, test mIoU **0.0586**; small-damage slice IoU val
  **0.0002** / test **0.0003** — weak aggregate gain, model still underfit.
- `CarddHybrid` parameter count: **3,206,855** (~3.2 M, base 32) — measured.
- Reproduction Git revisions: baseline checkpoint `cd2c9c1`; hybrid run
  `5eb8645` (both git-ignored artifacts).

**The research core is not finished**

- The hybrid-vs-baseline head-to-head comparison and the RQ2
  confidence-honesty operational metric remain open; only the MEASURED numbers
  above and the demo product are claimed so far.

## 3. Final Project Definition

**Research title (canonical, from the rewritten research report):**
*"AutoInspect-X: Photo-First Vehicle Damage Segmentation with Evidence-Labelled
Confidence"*

**Research question (locked):**
> How does the CNN+Transformer hybrid (`CarddHybrid`) compare against the plain
> U-Net baseline (`CarddUNet`) for damage-segmentation quality (mIoU, Dice,
> pixel accuracy, small-damage slice) and confidence honesty on CarDD, on
> identical splits, seed, and training schedule?

**Comparison arms (locked):**

| Arm | Design |
|---|---|
| A1 | `CarddUNet` + softmax CE, 5 ep (existing `cardd_baseline_ce`) |
| A2 | `CarddUNet` + same harness, extended schedule (separates underfit from architecture) |
| A3 | `CarddHybrid` + same schedule as A1 |
| A4 | `CarddHybrid` + extended schedule |

**Not in scope (ADR 0011):** repair-cost, repair-action, hidden-damage, physical
area in cm², multimodal fusion with vehicle metadata, questionnaire flow.

**Locked pipeline (the research flow the implementation must follow):**
user → capture-quality gate on the uploaded photo (PASS → analyze / FAIL →
retake guidance) → segmentation (7-channel argmax) → evidence payload (predicted
mask, per-class image-denominator area ratios, confidence, low-confidence flag,
overlay PNG) → honest explanation (LangChain ChatGroq or offline stub) →
consent → follow-up chat.
(Source: ADR 0011; the closing of the deleted dashboard panels in the frontend.)

**Architectural separation (locked, IMPLEMENTED):** the conversational model
(LangChain ChatGroq / stub) is NOT the segmentation model. No single giant
model, and no cost model exists at all.

## 12. Findings Interpretation

- **Underfit, not a failed method.** Everything (low IoU, near-zero small-damage,
  zero rare-class IoU, background-dominant accuracy) is consistent with a
  1-to-5-epoch training budget; the error analysis explicitly warns: "Draw no
  research conclusion from these numbers; they describe a 5-epoch underfit."
- **Precision > recall** means predicted damage is *usually real damage* but most
  is missed — FN-dominated, not a false-alarm problem.
- **Small damage is the highest-value gap**: crack/scratch localization drives
  the research core (per-damage features and the honesty signal). Until it moves
  off ~0, the vision arm cannot feed trustworthy damage features.
- **The old multimodal research question was unanswerable, so it was removed**
  (make/model/year, repair action, cost were all missing). ADR 0011 replaced it
  with a data-real question (A1–A4 hybrid-vs-baseline) that CarDD can answer.
- **Honesty by construction** (MODEL PREDICTION labels, DATA_UNAVAILABLE-at-nothing,
  low-confidence flag, consent, no-cost-fields tests) is the product's main
  defensible strength to date.

## 27. Ground-Truth Policy

From ADR 0004 + AGENTS.md (§3). Categories MUST stay distinct in code, data,
docs, and UI:

| Category | Meaning | Examples here |
|---|---|---|
| REAL GROUND TRUTH | Measured/verified by trusted source | CarDD COCO mask labels |
| WEAK LABEL | Approximate, noisy/indirect | (none in current data) |
| SYNTHETIC LABEL | Generated by rule/simulation/model | **none remaining in the API after ADR 0011** |
| DERIVED FEATURE | Computed, not observed | `damaged_pixels / total_image_pixels`, class fractions |
| MODEL PREDICTION | Model output | segmentation mask, confidence, `low_confidence` |
| ASSUMPTION | Team choice, not evidence | part-ratio limitation (ADR 0005/0009) |

Rules enforced here: a rule-generated cost table is **not** real cost truth;
synthetic hidden-damage labels are **not** validated evidence; physical area in
cm² is never claimed from uncontrolled photos — a normalized damage-area ratio is
OK when described as such.
